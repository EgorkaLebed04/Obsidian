## Что такое Obsidian

**Obsidian** — это приложение для создания персональной базы знаний на основе Markdown‑файлов. Ключевые особенности:

- **Локальное хранение.** Все заметки сохраняются как обычные `.md`-файлы в выбранной папке («vault»).
    
- **Двунаправленные ссылки** (`[[Note Name]]`) для связывания заметок между собой.
    
- **Graph View** — визуализация связей между заметками в виде графа.
    
- **Расширяемость** через тысячи плагинов от сообщества.
    
- **Полная приватность** — данные не уходят в облако по умолчанию.
    

## Поддержка Markdown в Obsidian

Obsidian поддерживает **стандартный синтаксис Markdown** плюс ряд расширений. Разберу по категориям:

### Базовое форматирование

- **Жирный текст:** `**жирный**` → **жирный**
    
- _Курсив:_ `*курсив*` или `_курсив_` → _курсив_
    
- ~~Зачёркивание:~~ `~~зачёркнуто~~` → ~~зачёркнуто~~
    
- `Моноширинный текст:` `` `код` `` → `код`
    

### Заголовки

```
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня
```

### Списки

- **Маркированный:**
    
    ```
    - Пункт 1
    - Пункт 2
      - Вложенный пункт
    ```
    
- **Нумерованный:**
    
    ```
    1. Первый пункт
    2. Второй пункт
    ```
    

### Блоки

- **Цитаты:**
    
    ```
    > Это цитата.
    > Она может состоять из нескольких строк.
    ```
    
- **Код:**
    
    - Встроенный: `` `код внутри строки` ``
        
    - Блок кода:
        
        ````
        ```python
        def hello():
            print("Hello, World!")
        ````
        
- **Горизонтальная линия:** `---` или `***`
    

### Ссылки и изображения


- **Внешняя ссылка:** `[Текст ссылки](https://example.com)`
    
- **Внутренняя ссылка (wikilink):** `[[Название заметки]]` — создаёт ссылку на другую заметку в вашем vault. Если заметка не существует, ссылка всё равно создаётся, и по клику можно создать новую заметку с этим именем.
    
- **Изображение:** `![[image.png]]` или `![Альтернативный текст](path/to/image.png)`
    

### Таблицы

```
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|------------|------------|------------|
| Ячейка A1  | Ячейка A2  | Ячейка A3  |
| Ячейка B1  | Ячейка B2  | Ячейка B3  |
```

### Дополнительные возможности Obsidian (расширения Markdown)

- **Теги:** `#тег` — для категоризации заметок.
    
- **Backlinks** (обратные ссылки) — автоматически показывают, какие заметки ссылаются на текущую.
    
- **Embedded notes** (встроенные заметки): `![[Название заметки]]` — позволяет отобразить содержимое другой заметки прямо внутри текущей.
    
- **Frontmatter** (метаданные в YAML):
    
    ```
    ---
    tags: [тег1, тег2]
    created: 2026-06-17
    status: draft
    ---
    ```
    
    Используется плагинами (например, Dataview) для запросов и фильтрации.
    
- **Математические формулы** (через MathJax):
    
    - Встроенная: `$E = mc^2$` → E=mc2
        
    - Вынесенная:
        
        ∫−∞∞​e−x2dx=π​
        
- **Диаграммы** (Mermaid):
    
    ```
    graph LR
      A[Начало] --> B{Условие}
      B -->|Да| C[Действие 1]
      B -->|Нет| D[Действие 2]
    ```

## Практические шаги для начала работы

1. **Скачайте Obsidian** с официального сайта (obsidian.md).
    
2. **Создайте vault** (папку для хранения заметок).
    
3. **Создайте первую заметку:** нажмите `Ctrl+N` или кнопку «New Note».
    
4. **Отформатируйте текст** с помощью Markdown.
    
5. **Свяжите заметки:** введите `[[` и начните писать название другой заметки.
    
6. **Посмотрите граф:** перейдите во вкладку **Graph View**, чтобы увидеть связи между заметками.
    
7. **Установите плагины** (по желанию):
    
    - **Dataview** — запросы к заметкам (как SQL для вашей базы знаний).
        
    - **Templater** — шаблоны для заметок (например, для ежедневных записей).
        
    - **Calendar** — календарь для ежедневных заметок.
        
    - **Excalidraw** — рисование схем прямо в заметках.
